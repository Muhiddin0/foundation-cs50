# Mashqlar

Bu papkada kitob boblariga tegishli qo'shimcha mashqlar va zarur bo'lsa
boshlang'ich kodlar saqlanadi.

## Nomlash qoidasi

Har bir bob uchun alohida papka ochiladi:

```text
exercises/
├── 01-kompyuter-asoslari/
├── 02-algoritmik-fikrlash/
└── ...
```

Mashq tavsifida quyidagilar bo'lishi kerak:

- vazifaning maqsadi;
- boshlang'ich fayllar;
- aniq talablar;
- kirish va chiqish namunalari;
- baholash yoki qabul mezonlari;
- ixtiyoriy yordam (hint).

Yechimlarni o'quvchi ko'rib qolmasligi uchun keyinchalik alohida
`solutions/` papkasida saqlash mumkin.
