## Manba qaydi uchun qolip

```md
### Manba nomi

- Havola: https://example.com
- Muallif yoki tashkilot: ...
- Foydalanilgan bob: ...
- Foydalanilgan mavzu: ...
- Litsenziya yoki foydalanish sharti: ...
- Oxirgi murojaat sanasi: YYYY-MM-DD
```

Manba g'oyani tekshirish uchun ishlatilgan bo'lsa ham qayd etilsin. Boshqa
muallifning matni, rasmi yoki kodini ishlatishdan oldin uning litsenziyasini
tekshiring.
